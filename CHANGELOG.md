# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.0.1-pre.alpha] - 2025-07-26

> Early pre-alpha public build  
> This is the first official GitHub release for public tracking.  
> Porting in progress from internal prototype made with [P-slice engine](https://github.com/Psych-Slice/P-Slice).  
> All chart progress and scripts are being migrated to the base Funkin engine.

### Added

- Initial structure of game project based on [Funkin engine](https://github.com/FunkinCrew)
- New character playable on Freeplay's Character Selector (Obviously)
- Added 3 playable charts (almost)
  - **Satisfaction** by kz(livetune)
  - **Far Away** by kz(livetune)
  - **Far Away (Project DIVA ver 2009)** by kz(livetune)
- 2 placeholder stages for some charts
- Temporary placeholder for Miku character sprite (from [Hatsune Miku - Project funkin'](https://gamebanana.com/mods/485992))
  - Original sprites will be created later
- Added custom themes from Project DIVA series to results screen

### Notes

- Internal version `v0` (prototype) made with [P-slice engine](https://github.com/Psych-Slice/P-Slice) is not public.
- This release marks the transition to GitHub-based development.
- `Reminder: This build is not representative of final quality.`
