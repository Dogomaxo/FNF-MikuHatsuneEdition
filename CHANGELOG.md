# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-pre.alpha] - 2026-03-21

> Early pre-alpha public build.

### Added

- Added a new "freeplayRandom" theme in the Freeplay menu when playing as Miku (from the Project DIVA series).
- Added a new Pause Menu theme when playing as Miku (from the Project DIVA series).
- Added the following playable charts (Hard mode only):
  - **ALL IS MUSIC!** by YZYX.
  - **DIVA** by Aiobahn & TAK.
  - **Decade** by Dixie Flatline.
  - **Ai kotoba V** by DECO*27.
* Added the **Voltage Power (PV)** mechanic:
  - Charges by hitting notes.
  - Grants a x2 score multiplier and temporary health bar invulnerability when active.
  - Temporarily changes strumline and note textures while active.
- Added new countdown sounds when playing as Miku.
- Added a temporary stage for charting (Testing Platform).
- Added the **Chance Time (CT)** mechanic:
  - Activates in special sections of a song.
  - Tracks note accuracy during the sequence.
  - Uses a final note that reflects success or failure visually.
  - Rewards successful completion with bonus score.

### Changed

- Replaced some song stages with temporary placeholders while custom stages are in development.
- Changed City Night Stage assets for a better one.
- Slightly updated Miku's freeplay backcard.
* Replaced Vanilla HUD with a new one for the mod.
### Fixed

* Tweaked Miku's health icon offsets.
* tiny bugs fixes.

### Notes

- `This will probably be the last update for the mod, as I’ve decided to start focusing on intensive studies for important things in my life, so this project would only consume more of my time. Besides, lately, instead of helping me relax or destress, it’s doing the exact opposite which is ironic because I started it specifically to de-stress lol. Finally, since I’m the only one trying to handle the mechanics, charts, programming, etc., I’ve been feeling an internal pressure that isn’t doing me any good mentally. If anyone sees this, I hope you can make the most of this likely unfinished project and give it the care it deserves. Thanks`
- `This version probably performs poorly because I made it too quickly and I don't have enough time and patience to fix it. I'm sorry`
